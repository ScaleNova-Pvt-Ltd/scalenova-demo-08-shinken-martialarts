Inspired by modern athletic martial arts web architecture (e.g. `karateacadamy.framer.website`), **Shinken Karate Academy** is an athletic membership portal engineered for dojos, sports academies, and combat conditioning facilities.

---

## 1. Key Highlights
- **High-Energy Contrast Theme**: Bushido crimson, titanium dark canvas, clean typography.
- **Interactive Daily Timetable**: Live schedule table with day/session filter tabs.
- **ScaleNova Master Lead Ingestion**: Synchronized via Google Apps Script to `Demo 8 - Shinken Karate`.

## 2. Integrated Pages
1. `index.html`: Hero, program pathways, sensei roster, interactive timetable, free trial banner.
2. `programs.html`: Curriculum breakdown from youth karate to national combat sparring.
3. `trial.html`: High-converting 60-second trial booking questionnaire.
4. `about.html`: Heritage, dojo kun virtues, and Dan grading syllabus.
5. `contact.html`: Location directions and dojo desk contacts.
6. `terms.html` & `privacy.html`: Membership regulations.
